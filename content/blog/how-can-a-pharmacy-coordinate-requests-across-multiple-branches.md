## Short answer

Give each request a responsible branch and a shared reference, then record when responsibility is transferred. A customer should receive a consistent account of which branch is handling the next step.

## Practical explanation

Confirm which branch has the relevant information or collection arrangement. Use an explicit handover rather than assuming that forwarding a message transfers ownership. Record acceptance by the receiving branch. Update customer communications to reflect the confirmed location and contact. Keep access to personal information limited to what the task requires. Review requests that remain unaccepted or have conflicting branch assignments.

## Example

A request moved from Branch A to Branch B should show the transfer time, the receiving owner and whether the customer has been told the new collection location.
