## Short answer

Include the collection location, applicable opening hours, reference and any instructions the pharmacy has confirmed. Use wording that accurately reflects whether the order is ready and what the customer needs to do next.

## Practical explanation

Verify the collection status before sending the message. Check the recipient and avoid including unnecessary sensitive details in a notification preview. Give a contact route for questions or changes. If several branches are involved, identify the correct one clearly. Keep a record of the message and any reply. Update the customer if the confirmed arrangement changes before collection.

## Example

A message saying “Your collection at the Nirala Nagar branch is ready, reference 214” gives a clearer action than “Please come” without a branch or reference.
