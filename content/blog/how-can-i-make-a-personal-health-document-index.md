## Short answer

Create a simple list of document names, dates, providers and storage locations. An index points to the original documents and helps you see what is available without opening every folder.

## Practical explanation

Start with the records you actually use for appointments. Add one row per document and include a link or clear folder location. Keep entries descriptive, avoiding your own interpretation of clinical findings. Update the index when a corrected document arrives. If another person helps maintain it, agree who records changes so two competing versions do not develop. Store the index with the same care as the records it describes.

## Example

An entry such as “12 November, clinic summary, Visits folder” tells you where to look without copying the summary's private contents into another file.
