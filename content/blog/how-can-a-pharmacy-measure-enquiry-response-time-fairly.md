## Short answer

Define the start and end events before calculating response time. Time to first acknowledgement, time to a useful answer and time to final resolution describe different parts of the customer experience.

## Practical explanation

Choose the measure that matches the question you want to answer. Record timestamps consistently and decide how closed hours or waiting for customer information will be handled. Report the number of enquiries included and keep unresolved items visible. Review unusual cases rather than hiding them in an average. Use the findings to identify process delays, then check whether the changes improve the same measure.

## Example

An immediate automated acknowledgement can coexist with a long wait for a staff answer. Reporting both stages makes that difference visible.
