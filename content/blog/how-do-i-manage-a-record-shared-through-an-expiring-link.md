## Short answer

Note the provider's instructions and expiry date, then obtain an authorised copy if you need the document for ongoing records. An expiring link should not be your only reference for an upcoming appointment.

## Practical explanation

Open the link through the expected provider channel and verify the document details. Download it if the service permits and store it in the appropriate private folder. Record where it came from. If access has expired, request a fresh copy from the provider. Avoid forwarding access codes broadly or attempting to work around the provider's access controls.

## Example

If a report link expires before next month's consultation, save the permitted report now or arrange a fresh copy through the provider before the visit.
