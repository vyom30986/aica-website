## Short answer

Create a dated note linked to the visit and record each question as it occurs. Separate questions about the clinic's process from questions that need a clinician's answer so they reach the right person.

## Practical explanation

Refer to the written consultation summary before sending a query. State which instruction or document you are asking about and explain what remains unclear. Use the clinic's designated contact channel and ask about expected response times. Record the reply with its date and source. If a question is still unanswered, keep it visible instead of marking the whole visit complete.

## Example

A note might say “Which number should I use to arrange the review?” followed by the receptionist's reply and the date it was confirmed.
