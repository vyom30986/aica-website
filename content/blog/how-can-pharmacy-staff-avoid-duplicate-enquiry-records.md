## Short answer

Search for an existing open request using an appropriate reference before creating a new one. Link follow-up messages to the original enquiry while preserving separate requests that genuinely involve different tasks.

## Practical explanation

Use a stable enquiry identifier and record the source channel. When a customer calls after sending a message, ask whether the call concerns the same request. Compare details before merging records. Keep a note of any merge so the conversation history remains understandable. Do not use a phone number alone to assume two records concern the same person, especially with shared family numbers.

## Example

A WhatsApp message and a later telephone call about one collection can belong to a single enquiry with two contact events.
