## Short answer

A useful message states the administrative request, provides the booking reference when available and includes a clear way to reply. Keep it focused so staff can route it without extracting the question from a long conversation.

## Practical explanation

Start with the action you need, such as rescheduling or checking whether a document arrived. Add the relevant date and reference. Use the clinic's approved channel for any sensitive details. If you have several unrelated requests, number them or send them through the appropriate processes. Avoid sending repeated versions of the same request before the clinic's stated response time has passed.

## Example

“Please confirm whether the two-page report for booking 214 arrived” gives the team a specific item to check and an outcome to report.
