## Short answer

Give each person a clearly named folder or profile and verify the selected person before adding a document. Shared surnames and similar filenames can otherwise make it easy to store a report in the wrong place.

## Practical explanation

Agree on a naming convention that everyone helping the family understands. Check the name on the actual document before uploading it. If two people have similar names, use an agreed additional identifier inside the private folder. Review newly added files periodically and correct misplaced copies. Restrict access to the people who need it and ask the person whose records you are organising how they want information shared.

## Example

Before sending a report to a clinic, check both the folder name and the patient name printed on the report.
