## Short answer

Offer a clear alternative contact route and record the reported problem so it can be investigated. Staff should know whether the request was actually saved before asking the customer to submit it again.

## Practical explanation

Check the enquiry queue for the customer's reference or reported time. If the request exists, continue from that record. If it does not, collect the necessary information through the pharmacy's approved alternative channel. Ask for the error message without requesting passwords or unrelated data. Report the technical issue and test the form after repair using a clearly labelled synthetic submission.

## Example

A customer seeing an error after pressing submit may still have a saved enquiry. Checking first helps avoid duplicate requests and conflicting responses.
