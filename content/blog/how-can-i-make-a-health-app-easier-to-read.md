## Short answer

Start with the device's supported text-size, display and accessibility settings, then test the screens used most often. A change is helpful when labels, buttons and documents remain readable and usable together.

## Practical explanation

Ask the person which screen is difficult. Increase text size gradually and check whether important controls still fit. Try the screen reader or other accessibility tools if the person uses them. Test forms, reminders and document views rather than only the home screen. Report clipped labels or inaccessible buttons to the app provider with a description of the affected device and setting.

## Example

A larger heading alone does not solve a small form label. Check the task from opening the app through submitting or saving the required information.
