## Short answer

Use a consistent filename that includes the document date, document type and provider. A predictable pattern makes a report easier to recognise than a camera filename such as IMG_4821, especially when several family members share a device.

## Practical explanation

Choose a pattern such as year-month-day, report name and clinic name. Keep each person's records in a separate folder rather than putting their full personal details into every filename. Use the date printed on the document and label an unknown date honestly. Preserve the original download when creating a renamed copy. Check the filename against the first page before storing it.

## Example

A filename such as “2026-11-12-lab-report-clinic-name.pdf” describes a document without making a clinical judgement about its result.
