## Short answer

Compare the download with the provider's description and check the patient details, date and page sequence. A file that opens successfully can still be missing a page or belong to a different visit.

## Practical explanation

Look for page numbers and attachments mentioned in the document. If the provider supplied several files, save each one and keep their relationship clear. Ask the provider about missing, unreadable or mismatched information. Keep the original file while requesting a corrected copy. Record that the document is incomplete so it is not accidentally treated as the final version at the next appointment.

## Example

If page one says “Page 1 of 3” and the download contains two pages, request the missing page before forwarding the bundle.
